# openIMIS Frontend Medical Controller module

This repository holds the files of the openIMIS Frontend Medical Controller module.
It is dedicated to be deployed as a module of [openimis-fe_js](https://github.com/openimis/openimis-fe_js).

[![License: AGPL v3](https://img.shields.io/badge/License-AGPL%20v3-blue.svg)](https://www.gnu.org/licenses/agpl-3.0)

## Main Menu Contributions

- Medical Controller (`medical_controller.mainMenu` translation key)

  **Missions** (`medical_controller.menu.missions` translation key), displayed if user has right `112000`.

## Other Contributions

- `core.Router`: registering the `medical-controller/missions` route in the openIMIS client-side router.
